# Inventory Management System

The Inventory Management System is a web-based application developed by using Django. This application helps small businessed efficiently manage products , vendors , inventory ,
purchase orders and stock alerts.This system provides a simple and user-friendly interface for monitoring inventory operations and generating reports.

## Features

- User Registration and Login
- Dashboard
- Product Management
- Vendor Management
- Inventory Management
- Purchase Order Management
- Low Stock Alerts
- Inventory Reports
- Inventory Forecast Page
- Responsive User Interface
